# БалИвКур

Учебный проект маркетплейса «БалИвКур» для лабораторных работ по разработке интерфейсов на React. Проектная спецификация находится в [`docs/project-spec.md`](docs/project-spec.md).

## О проекте

«БалИвКур» — каталог товаров нескольких продавцов. В планируемом интерфейсе покупатель сможет искать и фильтровать товары, просматривать цены и наличие, добавлять товары в корзину и избранное. Первая версия учебная: данные демонстрационные, серверной части и реальных платежей нет.

## Технологии

- React
- TypeScript
- Vite
- CSS

## Запуск

Когда приложение будет добавлено в репозиторий:

1. Установите Node.js и npm.
2. В корне проекта установите зависимости:

   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:

   ```bash
   npm run dev
   ```

4. Откройте адрес, который Vite выведет в терминале (обычно `http://localhost:5173`).

Для проверки production-сборки используйте `npm run build`. Если в проекте настроен ESLint, проверку стиля можно запустить командой `npm run lint`.

> На начальном этапе репозиторий содержит документацию проекта. Команды запуска станут доступны после добавления исходного кода React-приложения и `package.json`.
