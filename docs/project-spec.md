# Спецификация проекта «БалИвКур»

## 1. Назначение

«БалИвКур» — учебный маркетплейс, объединяющий предложения разных продавцов в одном каталоге. Проект предназначен для практики разработки интерфейсов на React, типизации с TypeScript и работы с демонстрационными данными.

## 2. Пользовательская проблема и цель

Покупателю приходится искать товары на разных площадках, сравнивать цены и характеристики, проверять наличие и условия покупки. Единый каталог с поиском, фильтрами и понятными карточками должен упростить выбор.

Цель первой лабораторной работы — определить требования к приложению, описать сущность товара, страницы, сценарии и границы первой версии, а также зафиксировать основу проекта.

## 3. Пользователи

- **Покупатель:** ищет товары, изучает карточки, отбирает товары, формирует корзину и проходит учебный сценарий оформления заказа.
- **Продавец:** в последующей версии сможет добавлять и редактировать предложения.

## 4. Основная сущность: Product

| Поле | Тип TypeScript | Пример | Назначение |
|---|---|---|---|
| `id` | `string` | `product-001` | Уникальный идентификатор |
| `title` | `string` | `Беспроводные наушники` | Название товара |
| `description` | `string` | `Bluetooth, чёрные` | Описание |
| `price` | `number` | `2490` | Текущая цена в рублях |
| `oldPrice` | `number \| null` | `2990` | Цена до скидки, если она есть |
| `category` | `string` | `Электроника` | Категория товара |
| `sellerId` | `string` | `seller-01` | Идентификатор продавца |
| `stock` | `number` | `15` | Остаток на складе |
| `rating` | `number` | `4.7` | Рейтинг товара |
| `imageUrl` | `string` | `/images/headphones.jpg` | Путь к изображению |
| `isFeatured` | `boolean` | `true` | Признак товара в подборке |

Для первой версии тип следует разместить в `src/types/product.ts`.

## 5. Страницы и маршруты

| Маршрут | Страница | Назначение |
|---|---|---|
| `/` | Главная | Подборки, категории и поиск |
| `/catalog` | Каталог | Все товары, фильтры и сортировка |
| `/product/:productId` | Карточка товара | Описание, цена и наличие |
| `/cart` | Корзина | Выбранные товары и итоговая стоимость |
| `/checkout` | Оформление заказа | Контактные данные и доставка в учебном сценарии |
| `/favorites` | Избранное | Сохранённые покупателем товары |
| `/seller/products/new` | Добавление товара | Форма для предложения продавца |

В рамках начального этапа фиксируется проектирование маршрутов. Полноценная маршрутизация может быть добавлена в следующих работах.

## 6. Основные пользовательские сценарии

1. **Поиск товара:** покупатель вводит запрос, просматривает совпадения и открывает карточку.
2. **Фильтрация каталога:** выбирает категорию и диапазон цен и просматривает подходящие товары.
3. **Добавление в корзину:** открывает карточку доступного товара, добавляет его и проверяет общую стоимость.
4. **Оформление заказа:** вводит контактные данные и выбирает доставку; фактическая оплата не выполняется.
5. **Размещение товара:** продавец заполняет название, описание, цену, категорию и остаток. Появление товара в общем каталоге относится к будущему этапу.

## 7. Первая версия

### Планируемый состав

- React-приложение на TypeScript, собранное с Vite.
- Тип `Product`.
- Локальный массив демонстрационных товаров: наушники, рюкзак, настольная лампа, кроссовки, термокружка и клавиатура.
- Стартовый экран с названием площадки, строкой поиска, категориями, подборкой и карточками.
- Отображение цены, рейтинга и наличия.
- Вычисляемые статусы товара:
  - `unavailable`: `stock === 0` — «Нет в наличии»;
  - `sale`: `stock > 0` и `oldPrice > price` — «Скидка»;
  - `available`: `stock > 0` — «В наличии».
- Адаптивные стили.
- README и эта спецификация.

Демонстрационные данные предполагается хранить в `src/data/mockProducts.ts`. Для вывода и расчётов достаточно методов массивов `filter`, `map` и `reduce`.

### Вне границ первой версии

Серверная часть, база данных, регистрация и авторизация, реальные платежи и заказы, интеграции доставки, личные кабинеты, отзывы, сохранение корзины, Redux Toolkit и полноценная маршрутизация.

## 8. Операции с товаром

В предметной области предусмотрены создание, просмотр, редактирование, удаление, поиск, фильтрация, сортировка, изменение наличия, добавление в избранное и корзину. Полноценное хранение и CRUD-операции относятся к последующим этапам; начальная версия использует локальные демонстрационные данные.

## 10. Технологии и команды

Для будущего приложения планируются React, TypeScript, Vite и CSS. После появления `package.json` ожидаются команды:

- `npm install` — установка зависимостей;
- `npm run dev` — запуск сервера разработки;
- `npm run build` — проверка и сборка приложения;
- `npm run lint` — статический анализ, если соответствующий скрипт настроен.

## 11. Критерии готовности проекта

- создан Git-репозиторий и сохранён первый коммит;
- подготовлены `README.md` и `docs/project-spec.md`;
- в последующих этапах создан проект React + TypeScript + Vite;
- определены тип товара и демонстрационные данные;
- описаны не менее шести маршрутов и пять пользовательских сценариев;
- зафиксированы операции над данными и ограничения первой версии;
- после реализации стартового экрана проверены запуск и production-сборка.

Состояние начального этапа: репозиторий содержит проектную документацию. Реализация приложения, запуск и сборка ещё не подтверждены.
